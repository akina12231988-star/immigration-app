# municipality-romaji.json の出典

都道府県・市区町村名のローマ字は、npm パッケージ `jp-address-romaji-data`（MIT License）の
`data/ja.json` から、名前とローマ字だけを取り出したものです。

- 元データ: デジタル庁「アドレス・ベース・レジストリ」 https://www.digital.go.jp/policies/base_registry_address
- 加工: Geolonia Inc.（`@geolonia/japanese-addresses-v2`・MIT License）

市区町村が増えたり名前が変わったりしたときは、同じパッケージの新しい版から作り直してください。
