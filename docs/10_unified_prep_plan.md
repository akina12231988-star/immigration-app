# 申請書類作成をアプリ一本化計画

2026-11-16 に利用者が名付けた計画。申請書類の準備を、入管の「提出書類一覧表」を見ながらアプリの中だけで進められるようにする。

## ねらい

- 申請準備の詳細画面で、入管の提出書類一覧表と**同じ番号・順番**に書類を並べる
- 書類ごとに提出確認欄の「有」「無」を選び、**「有」に○を付けた一覧表**を印刷して申請書類に付ける
- 「有」の書類は、その行から**添付・作成**していく（アプリにある書類はその場所へ、無い書類はその行に添付）
- 添付した書類をまとめた PDF も、一覧表の「有」の書類だけ・番号順にする

## 進め方（試験用ページ → 入れ替え）

- 新しい画面は **管理者だけが開ける試験用ページ** で作る
  - URL: `/workers/[id]/application-prep/unified`
  - 開けるのは `profiles.role = 'admin'` の人だけ（`src/lib/unified-prep.ts` の `canUseUnifiedPrep`）。それ以外の人は「見つかりません」
  - 今の申請準備の詳細画面の見出しの右に、管理者にだけ「一本化（試験中）」のリンクが出る（試験用ページからは「今の画面へ」で戻る）
- 中身は今の画面と同じ `ApplicationPrepChecklist` に `unified` を渡して出す。**保存先は今の画面と同じ**（同じ申請準備を見ている）
  - 試験中の機能は `unified` のときだけ出す。今の画面には出さない
- 利用者が試験用ページで動作を確かめ、問題が無いと言ったら、今の画面を入れ替える
  - 入れ替えは `PrepPage`（`src/app/(app)/workers/[id]/application-prep/PrepPage.tsx`）の `unified` を全員 true にし、
    試験中の印・リンク・`/unified` のルートを外す。そのときに更新のお知らせ（`src/lib/release-notes.ts`）を足す
  - 試験中の機能は管理者しか見ないので、それまで更新のお知らせには出さない

### ○を付けた一覧表の出し方（入管の様式の PDF に書き込む）

- 入管に出すので、アプリで作った表ではなく**入管の様式の PDF そのもの**に、提出確認欄の「有」「無」の丸と、表紙の氏名・所属機関名を書き込む（2026-11-17 の利用者の指示。エクセルでの出力は要らない）
- 様式の PDF は `public/forms/submission-*.pdf`、書き込む位置は `src/lib/submission-pdf.ts` の `SUBMISSION_PDF_TEMPLATES`
  - 位置は `node scripts/submission-pdf-layout.mjs <PDF>` で「有」「無」の文字の座標を読み取って書き写す（右側の官用欄は除く）
- 入っている様式: 1号 表紙＋第1表（`submission-ssw1.pdf`）、1号 農業の第3表の13の1（`submission-ssw1-agri.pdf`）、
  2号 表紙＋第1表（`submission-ssw2.pdf`）、2号 農業の第3表の8の1（`submission-ssw2-agri.pdf`）
- 2号の表紙＋第1表（在留資格変更許可申請用）は、利用者が入管のエクセルを Excel で PDF にしたもの（2026-11-17）
- 様式が無い表は簡易版（`submissionListPrintHtml`）で印刷する
利用者からもらった PDF はリポジトリに入れていない。

## 段階

1. **① 一覧表・有／無・○を付けた印刷**（済み・試験中）
   - 項目と見当の付け方: `src/lib/submission-list.ts`（テスト `submission-list.test.ts`）
   - 画面: `src/components/workers/PrepSubmissionList.tsx`
   - 保存: `application_prep_checklists.submission_marks`（0226）
   - 見当（最初から選んでおく）: 連名→1、変形労働時間制→6(3)(4)、あっせん→7(2)、国保→12・13、年金→14・15、
     国籍（カンボジア・タイ・ベトナム）→20、合格証の組み合わせ→農業の1、○の書類→有。4・7(1) などは選んでもらう
   - 印刷はアプリで同じ項目を並べた一覧表。入管のエクセルの様式で出すなら、ひな形をもらって書き込む形にする
2. **② 「有」の書類の添付・作成と、まとめた PDF**（済み・試験中）
   - 行ごとの揃え方: `src/lib/submission-list.ts` の `SUBMISSION_LINKS`
     - `docs`: 「必要な書類の準備」の書類（健康診断・税・年金・合格証・推薦状）。行には状態と、その書類の行へのリンク（`#prep-doc-<id>`）
     - `section`: アプリの中で作る章（申請書に貼る情報・雇用契約書・賃金・あっせん・1-17号・1-25号の日付・農業の加入通知書）へのリンク
     - `docs` が無い書類（と 15・20）は、その行に直接添付できる。保存は `onboarding_documents` の `prep_sl_<キー>`（例: `prep_sl_t1_4_1`）
   - 行の欄: `src/components/workers/PrepSubmissionList.tsx` の `SubmissionRowAction`（「有」の行の下に出す）
   - まとめた PDF: 一本化のページでは「有」の書類だけを一覧表の順に入れる（`submissionBundleOrder` → `prepBundlePlan(..., { keepOrder: true })`）。
     今の画面は今までどおり（`PREP_BUNDLE_ORDER` の順）
2.5 **参考様式の作成**（済み・試験中。0227）
   - 参考様式（1-4号・1-5号・1-6号・1-6号別紙・1-16号・1-3号・1-3号別紙・1-26号・1-17号・1-25号・1-2号・11-1号・11-4号）のひな形PDFを、
     様式・言語ごとに登録し（`ref_form_templates`。全員共通）、自治体の申請書と同じ操作で記入位置と「本人の署名が要るページ」を置く
     - 項目と書き込み・まとめ: `src/lib/ref-form.ts`（テスト `ref-form.test.ts`）
     - 記入位置の画面: `src/components/ref-forms/RefFormLayoutEditor.tsx`（`MunicipalFormLayoutEditor` を元にした）
     - ひな形の管理・行の欄: `src/components/ref-forms/RefFormPanel.tsx`、登録・削除は管理者だけ（`src/app/(app)/ref-forms/actions.ts`）
