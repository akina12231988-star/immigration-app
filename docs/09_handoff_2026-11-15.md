## 1. 作業の進め方（このリポジトリの約束ごと）

- 作業ブランチ: セッションごとに指定されたブランチ（今回は `claude/handoff-document-review-0ypkt5`）。
  1件ごとに `origin/main` から作り直して使い回す
  ```
  git fetch origin main && git checkout -B <作業ブランチ> origin/main
  git push --force-with-lease -u origin <作業ブランチ>
  ```
- 確認（コミット前に毎回）: `npx tsc --noEmit` → `npx eslint <変えたファイル>` → `npx vitest run` → `npm run build`
- 機能を足したら `src/lib/release-notes.ts` の `RELEASE_NOTES` の先頭に1件足す
- 利用者が「pr作成してマージ」と言ったら PR を作って squash でマージ（head の SHA は40桁で指定）。
  **言われるまでは PR を作らない**（今回、途中で「何もしないで」と止められた分がある → 4章）
- マイグレーションは利用者が Supabase の SQL Editor で手で適用する。SQL は回答の中に貼って渡す
- 利用者からもらったファイル（会社の情報が入った PDF・エクセルなど）はリポジトリにコミットしない
- 「新規引き継ぎ作成」「新規ページへ引き継ぎ」と言われたら、`CLAUDE.md` の手順（docs の handoff ＋ Obsidian 用ノート）で進める
