## 1. 作業の進め方（このリポジトリの約束ごと）

前回（11）の1章と同じ。今回あらためて気をつけたこと:

- 作業ブランチ（今回は `claude/vigilant-bardeen-u8sepy`）は、マージのたびに `origin/main` から作り直して `--force-with-lease` で上げ直す
- 確認は `npx tsc --noEmit` → `npx eslint <変えたファイル>` → `npx vitest run`（今回の最後で 226ファイル・2696件が通過）
- 利用者が「pr作成してマージ」と言ったら PR を作って squash でマージ（head の SHA は40桁）。言われるまでは PR を作らない
- このセッションの環境からは本番の Supabase を直接読み書きできない（service role での読み取りも止められた）。
  データの直しは利用者に画面で操作してもらう
- 画面の見本は、Claude の Artifact（Design のキャンバス「参考様式 作成画面の見本」）に artboard を足して渡した
  （作成画面・1-6号別紙の記入位置・本人に署名してもらう書類・ステータスの選択肢を足す手順）。実際の画面ではないことを必ず書く
- 利用者からもらった様式の PDF（納税証明書交付請求書など）はリポジトリに入れていない
- 更新のお知らせ（`src/lib/release-notes.ts`）は今回、一本化の試験中の機能にも足した（利用者が管理者で、使い方を見返すため）

## 3. 今回マージした変更（PR #779〜#807）

### 参考様式（一本化の試験中の画面から使う）
- **置く項目**: 年齢／性別で出し分ける○（男・女のときだけ）／支援計画書の日付すべて（「書き方」で西暦・令和・年・月・日。`fmt`）／
  書類作成日（全様式共通 `docAll`。年・月・日の項目も）／1-25号の契約期間（始め・終わり・〇から〇まで）／
  賃金（月給・日給・時給の金額と■）／1-6号別紙の計算結果（`w6_*`。手当(a)〜(d)・固定残業代・控除(a)〜(f)・手取り）／
  1-17号 支援計画書に記載する項目（`p117_*`。`src/lib/ref-form-117.ts`）／支援委託料（所属機関の月額）／
  証明書類の請求（個人番号は1マス1文字・マスの幅 `cell`、税務署名、代理人の氏名・住所）
- **記入位置の画面**: 置く項目をまとまりごとに開閉／見本の値が空の項目は項目名を出す／最大の幅を超える文字を2〜3行に折り返す（`maxLines`）
- **作成画面（試験中・0230）** `/workers/[id]/application-prep/unified/ref-form/[key]`: 自動で入る項目を書き込んだ PDF の上で、
  自由な文字を入力・○と文字をドラッグで移動・○を外す。印刷・PDFで保存・一時保存（`ref_form_drafts`）。
  文字ごとに「所属機関の共通にする」（`ref_form_org_texts`）、✓が無いまま保存するときは確認を出す
- **1-17号の PDF の最後に名簿**（支援業務を行う体制についての説明）を自動で付ける（`src/lib/support-system-pdf.ts`）
- **本人に署名してもらう書類**（入管には出さない）: 事前ガイダンス・生活オリエンテーションの確認書を言語ごとのひな形で作る（`guidance`・`orientation`）
- **保護（変更不可）付きの PDF** は登録のときにブラウザで画像の PDF に作り直す（`src/lib/pdf-unlock.ts`。cMap は `public/pdfjs/cmaps`）

### 申請準備
- 更新申請では「支援計画書の日付」の 1-17号・1-25号の枠と「１－１７号の…記載する項目」を出さない
- 一本化の画面で「署名・賃金」をなくし、「支援計画書の日付」を提出書類一覧表のすぐ上へ
- 提出書類一覧表: 有／無が未選択の参考様式の行にもひな形の欄／7(2) 人材サービス総合サイトの画面は全員共通の PDF（0153 の `support_org_files`）／
  協議会の構成員であることの証明書の行に所属機関の農業特定技能協議会の加入通知書
- 特定技能２号の申請で日本語・専門外の合格証を必要書類から外す（組み合わせが空でも２号として扱う）
- 1-6号別紙の固定残業代に手当の名前・「〇時間を超える」時間数（`fixed_ot_name`・`fixed_ot_over_hours`。jsonb なのでマイグレーション不要）
- 推薦状の準備状況に「住民票を郵送請求中」「住民票を代理人で発行依頼中」
- 「源泉徴収票をもう1枚追加」が効かなかったのを直した

### 証明書類の請求
- 納税証明書交付請求書（税務署）を、登録した様式（`ref_form_templates` の `nozei3`）と記入位置で作る（無ければ従来の様式）
- 自治体マスタに住民票の申請書・委任状（0231）、納税証明書の別の申請書（0232）
- 自治体の申請書の「自由な文字」を請求ごとに直す、「開いて確認・印刷」をアプリ内の確認画面（PDF を見ながら直して作り直す）に、
  ✓・○ を請求ごとに外す・動かす（`texts`・`marks`）
- 代理人の情報（フリガナ・住所・生年月日・電話番号）を代理人ごとに登録（app_settings `mailing_agents`）し、自治体の申請書の代理人の欄に置ける
- 課税・納税証明書の判定結果の欄でも申請書の「開いて確認・印刷」

### そのほか
- 外国人雇用状況届出書（様式第3号・雇入れ）の ⑦ を「②無」に
- 求職一覧で間違えて登録した応募を削除
